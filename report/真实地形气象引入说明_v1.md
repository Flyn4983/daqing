## 一、背景与核查结论

用户要求核查"真实地形、天气是否已引入软件"，并建议在 GitHub 等寻找开源资源直接用于原型样机。核查结论如下：

| 项目 | 核查前现状 | 证据 |
|---|---|---|
| 地形（7 个想定） | 2 个标 `source: geotiff`，但 YAML 自述用的是"385² **合成**峡谷"；其余 5 个 FBM 程序噪声 | `example_brigade.yaml:21`、`kernel/terrain.py:64-82` |
| 前端 3D 地形 | `terrain.js` 浏览器端随机 FBM（7 preset），非真实数据 | `terrain.js:7-48` |
| 气象 | 9 种天气的经验衰减矩阵，源码自述"待真实数据替换" | `combat/weather.py:11-12` |

**结论：核查前软件里没有任何真实地形/气象数据，全部为合成/经验值。** 本版已完成真实数据引入。

## 三、引入的真实数据（已落盘）

### 3.1 真实地形 DEM —— 太行山中段

- 区域：太行山中段，山西-河北交界（37.00°N / 113.50°E），华北典型山地丘陵
- 数据源：AWS Terrarium（SRTM/ASTER GDEM 派生），zoom=12，约 30m 分辨率，3×3 瓦片拼接
- 实测高程：**879~2052m**（起伏 1173m），含真实山脊、Y 字形河谷水系
- 通行性栅格：由真实高程坡度派生（0.2~1.0），河谷走廊抬升通行性
- 文件：
  - `scenarios/terrain/dem_real_taihang.tif`（高程）
  - `scenarios/terrain/pass_real_taihang.tif`（通行性）
  - `scenarios/terrain/REAL_TERRAIN_META.json`（溯源元数据）
- 采集脚本（可复现）：`tools/fetch_real_dem.py`

### 3.2 真实气象 —— ERA5 再分析

- 区域：与 DEM 同区域（太行山中段）
- 时段：2024-07-10 ~ 2024-07-12（72 小时）
- 数据源：Open-Meteo Historical Weather API（ECMWF ERA5 再分析，0.25°）
- 字段：温度/降水/风速/风向/湿度/WMO 天气码，并映射为本项目的 weather 枚举与能见度因子
- 天气分布：clear 32h / overcast 22h / rain 18h（真实天气序列）
- 文件：
  - `src/brigsim/agent/web/data/real_weather.json`（离线打包）
  - `scenarios/REAL_WEATHER_META.json`（溯源元数据）
- 采集脚本（可复现）：`tools/fetch_real_weather.py`

### 3.3 WMO 天气码 → 本项目枚举映射

| WMO code | weather | 基础能见度因子 |
|---|---|---|
| 0-2 | clear | 1.00~0.95 |
| 3 | overcast | 0.85 |
| 45/48 | fog / heavy_fog | 0.20 / 0.10 |
| 51-67 | rain | 0.45~0.70 |
| 71-77 | snow | 0.50~0.60 |
| 80-99 | rain / heavy_rain | 0.30~0.70 |

降水 ≥2mm/≥5mm 时能见度因子再乘 0.88/0.75。映射与 `combat/weather.py` 的传感器衰减矩阵口径一致。
