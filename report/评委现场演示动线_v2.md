## 动线三：交战推演 + 3D 态势（2 分钟）

1. 顶部工况下拉选想定（7 个：中型旅快攻/深切峡谷/平原浓雾等）→ 3D 场景随之切换。
2. 中部 3D 回放：地形、红蓝单位、 Coverages 清晰渲染（同源代理，零外网）。
3. 【返回/切换验证】3D 面板"同源/直连"按钮可切换数据通道；黑屏时自救卡三按钮（重试/切换/强刷）可用。
4. 【返回按钮验证】点"实时推演"弹配置窗 → "重置默认值" / "✕ 关闭" / "开始推演" / 顶部"■ 停止"均有正确响应（已自动化验证）。

## 动线四：智能参谋 · 真实大模型制定方案（3 分钟）—— 本次核心亮点

1. 点右上 **智能参谋** 开抽屉（【返回】点"收起×"或 Esc 关闭，已验证）。
2. 点 **knee 折中推荐** 一键生成：
   - 前半部分：真实数字表格（来自代理预测 + Pareto + 守卫复验内核）；
   - **口径标注**：明确"代理预测值 vs 文档终审 0.650"来源不同；
   - 后半部分：**"方案制定说明（本地大模型生成）"** —— 由本机 Qwen3-32B 基于真实数据生成的可解释说明，附"耗时 xx ms / 数字均来自内核"标注。
   - 角标显示 `● 本地大模型真实生成`（若模型未起则显示 `○ 内置模板`，如实不误导）。
3. 再点 **leanest 资源最省** / **strongest 保障最强**，对比三档方案。
4. 在输入框问："如果只派 3 个抢修组、4 辆抢救车，四率会怎样？" → whatif 代理测算。
5. 问："Pareto 前沿一共给出了哪些方案？" → 74 个非支配解。
