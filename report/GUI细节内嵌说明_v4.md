## 一、这版改了什么（与 v3 的区别）

v3 做的是顶栏「研究细节」集中弹窗（6 个标签页），评委要主动打开、翻页找。
v4 在**原界面上就地嵌入**细节入口，不改变任何控件的功能与数据逻辑：

| 载体 | 新增元素 | 交互 | 覆盖 |
|---|---|---|---|
| 配置弹窗参数项 | 蓝色圆形 **ℹ** 按钮（label 右侧） | 点击弹出该参数对应的报告模型/公式/可行域/权威数字 | 21 项 |
| 配置弹窗每个设置组 | 蓝色"报"字**报告映射说明带**（组标题下） | 常驻显示，一眼看到该组对应报告哪一部分 | 7 组 |
| 图表面板 | 橙黄色 **ℹ** 按钮（标题右侧）+ 图表下方**报告锚点带** | 点击看公式口径验证数字；锚点常驻显示式号/图号 | 5 图 |
| 工况下拉 / 快速预设 | 每个选项 **title 悬浮说明** | 鼠标悬停看想定细节 | 7 想定 |

所有数字从 `/data/verification.json` 实时读取（由 `tools/build_verification_data.py` 从真实 JSON 实算），沿用 🟢真实数据实算 / 🟡报告正文 角标，**不冒充实时读取**。

## 二、配置弹窗：参数项 ℹ 明细（21 项）

点配置弹窗任一参数右侧的 **ℹ**，浮层显示该参数在报告里的"身份"。重点项：

**③ 保障资源旋钮 —— 报告"一阶决策变量"（核心）**
- 并行抢修组数 x₁：可行域 2~10；模型二 MTTR≈MTTR₀·exp(Q/c)；报告 6/10/14 组 MTTR 相对 1.00/0.72/0.69
- 装甲抢救车 x₂ / 器材补给车 x₃ / 携行档 x₄ / 运行档 x₅ / 波次节拍 x₆ / 每波件数 x₇：各自可行域（来自 verification.json 实算 74 解的 7 维档位）+ 对四率的作用

**② 环境与气象 —— 灵敏度 rank1**
- 能见度系数：**Sobol ST=0.758（蓝方战损率 rank1）**，公式 Sᵢᵀ=1−E[Var(f|X_∼i)]/Var(f)
- 天气 / 光照：气象光照差异化建模，3D 回放对应渲染

**④ 情景因子 —— 二阶固定条件**
- MTBF / 红蓝效能乘子：两阶段随机优化（图10）的情景抽样维度，LHS+公共随机数 CRN

**①⑤⑥⑦ 组**：想定矩阵（表2）、8 族 FBM 地形、红蓝差异化能见度、风场——各有对应说明。

**三源约束 A/B/C/D** 在 ③ 组说明带里点明落点（成本软目标 C / 档位边界 A·B / 终审守卫 D）。

## 四、现场演示怎么用（3 个动作）

1. **指参数**：点顶栏「▶实时推演」（live 模式）→ 配置弹窗 → 点任一旋钮的 **ℹ** → 对着浮层讲"这是报告一阶决策 x₁，可行域 2~10，对应 MTTR 指数饱和式(6)"。组标题下的蓝色说明带不用点，直接念。
2. **指图表**：主屏任一图表标题右侧 **ℹ** → 浮层给出公式与权威数字，图表下方锚点带常驻显示式号图号，评委不用翻文档就能对上。
3. **指想定**：工况下拉每个选项悬停即显示想定细节（地形/气象/编制）。

浮层三种关闭：✕ / Esc / 点空白处，演示中随手关。
